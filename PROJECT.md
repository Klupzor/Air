# Project Map

AIR is a Markdown-only methodology for making software projects readable by AI coding agents. This file only points to canonical locations.

| Topic | Location |
|---|---|
| Domain (what AIR is, its concepts and principles) | [`SPEC.md`](SPEC.md) |
| Features (what AIR does: Discovery, Implementation, Context Impact, Adoption) | [`SPEC.md`](SPEC.md) and the procedures in [`skill/references/`](skill/references/) |
| Architecture | [`blueprint/architecture.md`](blueprint/architecture.md) |
| Modules (which file owns which concept) | [`blueprint/modules.md`](blueprint/modules.md) |
| Rules (how AIR's own documents are written) | [`blueprint/rules.md`](blueprint/rules.md) |
| Decisions | [`blueprint/decisions.md`](blueprint/decisions.md) |
| Current implementation intent | `current-task.md` (present only while a task is active) |

Domain and Features point at existing documents instead of separate `blueprint/domain.md` and `features/` files — AIR's own rule for existing projects: an existing document can be the canonical home for a category.
